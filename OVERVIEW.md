# Обзор проекта

Эта шпаргалка помогает быстро представить архитектуру и назначение каждого файла с кодом в репозитории.

## Основные пакеты

### python_defrag/analysis/analyser.py
Класс `FAT32Analyzer` обходит дерево каталогов образа FAT32, строит цепочки кластеров, вычисляет статистику фрагментации и предоставляет удобный отчёт (списки файлов, директорий и свободных экстентов). В файле также определены структуры данных (`FileRecord`) и утилиты для расчёта экстентов и сводного вывода.

### python_defrag/parser/fat32_parser.py
Низкоуровневый парсер FAT32-образа. Умеет открывать файл, читать/писать кластеры и записи FAT, вычислять смещения, синхронизировать изменения. Этот слой предоставляется как безопасный контекст-менеджер, на котором построены другие компоненты.

### python_defrag/parser/directory_entry.py
Парсер 32-байтовых записей каталога FAT32. Конвертирует «сырой» поток байтов в объекты `DirectoryEntry`, корректно разбирает даты/время и фильтрует удалённые или LFN-записи. Используется анализатором при обходе каталогов.

### python_defrag/engine/defrag_engine.py
Дефрагментационный движок. Планирует переносы, копирует данные кластеров, обновляет цепочки FAT, корректирует записи каталогов и формирует итоговый отчёт. Особое внимание уделено безопасности записи (работа с копией образа, логирование ошибок, рекурсивный обход каталогов при обновлении ссылок).

### python_defrag/engine/cli.py
CLI-инструмент для запуска анализа и дефрагментации. Поддерживает режимы только анализа, планирования или полного выполнения и выводит итоги в консоль.

## Тесты и вспомогательные скрипты

### tests/test_engine.py
Юнит-тесты дефрагментационного движка. Проверяют инициализацию, анализ образа, планирование перемещений и корректность структуры каждой запланированной операции.

### tests/test_integration.py
Интеграционные тесты для связки парсер+анализатор. Убеждаются, что извлекаемая статистика и обход каталогов выглядят разумно.

### tests/test_all.py
Сценарий «smoke-тестов», который последовательно выполняет проверки парсера, анализатора, интеграции и движка (можно отключать блоки флагами). Удобен для демонстрации преподавателю.

### tests/test_parser_cli.py и tests/test_analyser_cli.py
Мини-CLI для ручной проверки парсера и анализатора с выбранным образом. Полезны для быстрой демонстрации загрузки boot-сектора и списка файлов.

### tests/test_fragmented.py
Заглушка под будущие проверки сценариев с сильно фрагментированными образами.
