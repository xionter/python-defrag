# python-defrag
Инструмент для анализа и дефрагментации образов FAT32. По умолчанию строит план перемещений (dry-run), при необходимости создаёт новый образ с объединёнными кластерами.

## Быстрый запуск
- Запуск анализа без записи:  
  ```bash
  python -m src.cli path/to/image.img --dry-run
  ```
- Создание нового образа с выполнением плана:  
  ```bash
  python -m src.cli path/to/image.img --execute -o images/defragmented.img
  ```
  По умолчанию результаты записываются в `images/` с отметкой времени.
- Только собрать отчёт о фрагментации без плана: `python -m src.cli path/to/image.img --analyze-only`
- Отключить проверку нового образа после записи: добавьте флаг `--no-verify`.

## Что делает
- Парсит загрузочный сектор FAT32 и таблицу FAT, собирает сведения о файлах и свободных участках.
- Планирует перенос кластеров так, чтобы крупные фрагментированные файлы получили непрерывные области.
- Может выполнить план на копии образа и обновить цепочки FAT и записи каталогов.
